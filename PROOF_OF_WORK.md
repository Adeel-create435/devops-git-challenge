## Q1: Difference between Git and GitHub
Git is a version control system used to track code changes locally. GitHub is a cloud platform that hosts Git repositories. Git works on a local computer, while GitHub enables remote backup and collaboration. Developers use both tools together to manage projects.

## Q2: Three Git Architecture Stages
The Working Directory contains files being edited. The Staging Area contains changes selected for the next commit. The Local Repository stores committed versions of the project. These stages help developers manage changes systematically.

## Q3: Difference between git stash pop and git stash apply
Both commands restore changes saved using git stash. The git stash pop command restores changes and removes the stash entry if successful. The git stash apply command restores changes but keeps the stash entry. Apply is useful when the same saved changes may be needed again.

## Q4: Difference between git fetch and git pull
The git fetch command downloads updates from a remote repository without integrating them into the current branch. The git pull command fetches updates and integrates them into the current branch. Fetch allows you to inspect remote changes before integrating them. Pull is useful when you are ready to update your local branch.
